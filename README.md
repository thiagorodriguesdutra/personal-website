# thiagodutra.net

Meu site pessoal, em português, inglês e espanhol: **https://thiagodutra.net**

[English](README.en.md)

Feito só com HTML, CSS e um pouquinho de JavaScript. O visual foi inspirado no site do [Nicholas Matsakis](https://nick.matsakis.net/).

## Rodando localmente

```sh
python3 -m http.server
```

Depois é só abrir http://localhost:8000.

## Publicação

O site fica no GitHub Pages. Qualquer push na `main` já vai pro ar.
