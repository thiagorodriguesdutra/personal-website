# thiagodutra.net

My personal website, in Portuguese, English, and Spanish: **https://thiagodutra.net**

[Português](README.md)

Built with plain HTML, CSS, and a tiny bit of JavaScript. The design is inspired by [Nicholas Matsakis](https://nick.matsakis.net/)'s website.

## Running locally

```sh
python3 -m http.server
```

Then open http://localhost:8000.

## Deployment

The site is hosted on GitHub Pages. Every push to `main` goes live.
